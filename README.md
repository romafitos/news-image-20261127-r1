One 1024×1024 front page summing up Friday 27 November 2026: 36 dated stories across 7 regions plus global, three pictorial heroes (Kuwait drone strike, Black Friday, Gaza), ten picture cards, a numbered-pin world map, a numbers strip, a DAY IN UTC timeline, and a DATE CHECK box naming the big older stories deliberately left out. Every picture and the map are drawn in code with Pillow from fixed coordinates — no network, no randomness — so the program writes byte-identical PNGs on every run.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.png` (1024×1024, PNG).
